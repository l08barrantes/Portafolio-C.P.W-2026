Horario y guía del curso

Materiales necesarios

Para trabajar en el módulo hace falta:

  • Computadora con acceso a internet
  • Visual Studio Code instalado
  • Cuenta de GitHub con el correo verificado
  • Cuaderno de bitácora

Cómo entregar una práctica

El protocolo se repite en todas las sesiones:

  1. Traer los cambios con git pull
  2. Crear la rama de la práctica
  3. Trabajar y hacer commits atómicos
  4. Subir la rama con git push
  5. Abrir el Pull Request
  6. Revisar y fusionar
  7. Volver a la rama principal y actualizar
  8. Eliminar la rama local

Los pasos no son intercambiables: no se puede hacer un commit antes de crear la rama.

Glosario

Commit
Instantánea permanente del proyecto en un momento dado.
Rama
Línea de trabajo paralela que no afecta a la rama principal.
Pull Request
Solicitud de revisión para incorporar una rama al proyecto.
Repositorio
Carpeta del proyecto con todo su historial de cambios.
