Presentación del módulo

Sobre el módulo

Este módulo comprende 150 horas distribuidas en cinco unidades de aprendizaje. Se estudia la construcción de páginas web desde su estructura hasta el uso de un framework de diseño.

El enfoque es eminentemente práctico: cada sesión produce una evidencia que se incorpora al portafolio personal.

Se aprende primero a construir a mano para comprender qué hace un framework y poder decidir cuándo conviene usarlo.

Principio metodológico del módulo

Las cinco unidades

El recorrido avanza de la estructura a la presentación:

  1. Implementación de control de versiones
  2. Empleo de etiquetas y atributos HTML
  3. Codificación de hojas de estilo
  4. Elaboración de páginas web responsivas
  5. Uso de frameworks y librerías

El detalle de cada sesión está en la página de horario.

Cómo se evalúa

Cada unidad cierra con una actividad de comprobación. Como dice el instrumento, la evaluación es por producto: se valora el proyecto entregado, no un examen escrito.

Para matricularse en una sesión de refuerzo puede usar el formulario de registro.

Aviso

Las actividades de comprobación se aplican en las sesiones 9 y 10. Consulte el calendario completo.
